Old-fashioned Typesetting vs Desktop Publishing

Old-fashioned typesetting involved manually arranging individual letters and printing blocks to create physical pages, whereas desktop publishing lets users host text online, using HTML to control content and structure and CSS to control its appearance. Old-fashioned typesetting is time-consuming and difficult to change once the type is set. Instead, desktop publishing is easy to edit and collaborate on.
