Emphasis and strengthened text

This paragraph demonstrates emphasized and strong text. Emphasized text causes text to stand out from surrounding text; usually displayed in italics. Emphasized text is created by using the tag < em >. Strong text causes text to stand out from surrounding text; usually displayed in bold. Strong text is created by using the tag < strong >.

... Separating content from presentation

Explanation

Emphasized < em > and strong < strong > text are semantic markups that attribute meaning to text, while italic < i > and bold < b > tags only convey visual style. While both sets of markups look similar, it is important to use < em > and < strong > over < i > and < b > so that screen readers and search engines can pick distinguish them.
